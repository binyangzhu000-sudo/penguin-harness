# Learn reusable workflow skills with AWM

- **Date:** 2026-10-02
- **Type:** feature
- **Scope:** plugins

[中文版](2026-10-02-rsi-awm.zh.md)

Added the optional `rsi-awm` plugin. An Agent follows the Skill to run tasks,
judge success from public execution evidence, extract parameterized workflows,
and install those workflows as target-owned Skills for later tasks. Failed or
uncertain experiences do not become workflows. Held-out evaluation keeps the
learned library frozen.

The plugin includes its execution contract, workflow format and paper reference.
It uses the existing Agent Tuning evaluator without changing that plugin. Core,
CLI and desktop register the same optional package. Its public landing-page
listing is deferred while the algorithm is being tested.
