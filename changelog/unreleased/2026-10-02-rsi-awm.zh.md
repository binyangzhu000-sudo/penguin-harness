# 用 AWM 学习可复用的流程技能

- **Date:** 2026-10-02
- **Type:** feature
- **Scope:** plugins

[English](2026-10-02-rsi-awm.md)

新增可选的 `rsi-awm` 插件。Agent 按照 Skill 执行任务，根据公开执行证据判断是否成功，再提炼参数化流程，保存为被测 Agent 自有的 Skill，供后续任务使用。失败或无法确定成功的经验不生成流程，留出集评测期间冻结已学技能。

插件包含执行约定、流程格式和论文出处。它复用现有 Agent Tuning 评测员，不修改该插件。Core、CLI 和桌面端登记同一个可选包；算法试验期间暂不加入官网展示清单。
